A harness manager runs a task whose board-minted id isn't a usable identity segment, such as a coordinator's routed task (`routed:<request>:<round>:<delegate>`): a task that names no issue runs under `taskIssueSegment(taskId)`, the id itself when it fits and an `h-` hash otherwise. A session door's `runOf` keys a row's run with the same export. A conversation-result task whose output carries an `answer` string, as a coding run's does, now lands that answer in the conversation, routed or not (FIX-2270).
