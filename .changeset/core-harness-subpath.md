**Breaking:** the coding-harness vocabulary moves to a new public subpath, `@flow-state-dev/core/harness`, its one home (FIX-2448). It holds the harness contract (`HarnessBlock`, `HarnessRunInput`, `HarnessRunHandle`, `harnessRunInputSchema`, `harnessRunHandleSchema`, the hook types, `reportHarnessSpend`), the run's plan record (`OBSERVED_PLAN`, `observedPlanCollection`, `replacePlanList`, `readPlanTarget` and the rest), the session's pull-request record (`OBSERVED_PULL_REQUESTS`, `observedPullRequestsCollection`, `recordPullRequests`, `pullRequestRecorder`, `githubPullRequestRule` and the rest), and the helpers a harness calls (`harnessEnv`, `harnessSteering`, `reportHarnessActivity`, `harnessActivityOf`, `formatRunDuration`). These names are no longer exported from the `@flow-state-dev/core` root or from `@flow-state-dev/core/types`, with no deprecated aliases: an old import fails to compile with "has no exported member"; change it to `from "@flow-state-dev/core/harness"`. Like `core/types`, the subpath is safe to import from browser code. `planConversationPrefix` and `findOpenedPullRequests` are removed from the public API with no new home.
