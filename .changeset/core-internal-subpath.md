**Breaking:** core's runtime seams move off its public entries to `@flow-state-dev/core/internal`, a subpath for the framework's own packages (FIX-2448). It holds the request host (`RequestHost` and its verb types, `requireRequestHost`, `NoRequestHostError`, and the new `requestHostOf`), the wait gate (`parkOnWait`, `canHoldWait`, `waitOnRequest`, `WAIT_DEADLINE_ENTRY`, `MAX_WAIT_DEPTH`, `WaitOutcome` and the rest), the dispatch seam (`DISPATCH_SEAM`, `dispatchThroughSeam`, `NoDispatchSeamError`), the request-end and spend seams (`REQUEST_END_SEAM`, `onRequestEnded`, `REQUEST_SPEND_SEAM`, `readRequestSpend`, `RequestEnding` and the rest), the resume and board-notice seams, the request's side-chain pool, `buildReplayLog`, `resolveActiveStatusMessage`, `resolveAllowedActions`, `cacheTokensOf` and `isFiveFieldCron`. These names are no longer exported from the `@flow-state-dev/core` root, `@flow-state-dev/core/types` or `@flow-state-dev/core/errors/suspension-error`, with no deprecated aliases: an old import fails to compile with "has no exported member". `@flow-state-dev/core/items/internal` is removed; its names (`BlockValueInternal`, `RuntimeItem`, `refBlockValue`, `resolveBlockValueInternal`, `parseBlockInstanceId`) are on `@flow-state-dev/core/internal`, and `RuntimeItem` stays public on `@flow-state-dev/core/items`. The public `BlockContext` type no longer declares `requestHost` or the five symbol-keyed seam slots; they are on `InternalBlockContext`, which the engine builds. Code that read `ctx.requestHost` reads `requestHostOf(ctx)`, which is `undefined` when no host is wired, as the optional read was. Apps should not import any `/internal` path: CI refuses it from app, example and docs code.

Docs: packages/core/README.md (drop the runtime-seam passages — `ctx.requestHost`, the dispatcher's substrate exports, the wait gate, the request-end and request-spend seams — and move them to docs/architecture/internal-execution-seams.md; no README import of these names from the root or `core/types` remains), packages/orchestration/README.md (`canHoldWait` is imported from `@flow-state-dev/core/internal`, not re-exported from the root; `ctx.requestHost` reads become `requestHostOf(ctx)`), packages/workforce/README.md (a host whose request host carries `sessions`, read with `requestHostOf(ctx)`), packages/engine/README.md (`RequestHost`, `WAIT_DEADLINE_ENTRY` and `parkOnWait` are framework seams on `core/internal`), packages/contracts/README.md (its internal items are re-exported from `@flow-state-dev/core/internal`, not `core/items/internal`), apps/docs/docs/patterns/utility-blocks/core.md (the session-history tool reads the host's `sessions.history`; drop `ctx.requestHost`)
