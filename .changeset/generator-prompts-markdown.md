Author generator prompts as external `.md` files. Two new subpath exports: `@flow-state-dev/core/prompt-file` (isomorphic — `parsePromptFile`, `definePromptFile`, types) and `@flow-state-dev/core/prompt-file/node` (`loadPromptFile`, with sibling-`.md` partial auto-discovery). A prompt file carries YAML frontmatter for metadata plus `<system>` / `<user>` / `<context>` role-tagged sections rendered through LiquidJS at generator-call time against `{ input, ctx, config }`. The new `config` namespace exposes the resolved model id, tools, caching, and the aggregated context tag map (`config.context`). A `<context>` block opts the template into owning context rendering, suppressing the framework's default XML-tag append so the author can reorder, conditionally include, or restructure capability-contributed context. Shared fragments compose via `{% render %}` partials; value transforms use built-in or per-file custom Liquid filters. The existing inline `prompt: string | (input, ctx) => string` surface is unchanged — `.md` prompts are additive, adopted incrementally. The block trace gained `templateSource` and `templateFrontmatter` for prompt-file-sourced generators.
