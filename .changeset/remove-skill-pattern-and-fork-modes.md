Remove the `pattern` and `fork` skill context modes and deliver delegation as a board-commanded agent team. A skill is now inline instructions, optionally plus a team of agents; `SkillContextMode` collapses to `"inline"`.

- `@flow-state-dev/core`: `SkillContextMode` is now the single value `"inline"`; the `PatternBinding` and `TaskInitYaml` types and `SkillState.outputSchema` are removed. `WorkerSpec` is renamed to `AgentSpec` and its resolution fields collapse to an inline agent (`prompt`/`prompt-ref` + `tools`/`model`/`visibility`) or a registry `agent-ref` (+ `agent-overrides`) — `blockRef` is removed. `SkillState` gains a top-level `agents` field (was `workers`).
- `@flow-state-dev/orchestration`: delegation is derived from a bound skill's `agents:` on `createSkillsLibrary`. It installs a private own-state task board, the eight `taskTools` (whose `addTask` accepts a structured `input` payload), and `runBoard` — a `taskBoard(...).drain` over that board. The board is the execution mechanism: the skill assigns work as tasks (`addTask` with an `assignee` naming an agent, plus `deps`/`input`) and drains the graph with one `runBoard` call, under concurrency and dependency gating. There are **no per-agent host tools**. Agents materialize at runtime through the generator's async tool seam: inline agents build a board worker; `agent-ref` agents resolve via the `agentRegistry`/`materializeAgent`/`capabilityCatalog` library options. Identical agent specs shared by two active skills dedupe; divergent specs under one key fail loud at build. The fork generator and the `runSkill` pattern/fork routes are removed (`runSkill` also rejects stale pre-migration non-inline manifests loudly), and the `taskTools` board-resolution sentinel is `no_delegation_board`. Legacy `workers:`/`block-ref` frontmatter fails loud at parse with a migration message. Assigning a task directly to a tool is a follow-up (FIX-925); for now assign it to an agent that carries the tool. Deterministic flows like `goalSeekLoop` and `taskBoard().drain` can still be placed in a generator's `tools:` and called as a single tool.
- `@flow-state-dev/patterns`: the `defaultPatternRegistry` / skill-pattern binding is removed; the pattern factories themselves are unchanged.
