Shift Manager's Inbox, its count, Tasks, the shift summary's needs-you numbers and a task's asks read one server answer, workforce's inbox view, so they always agree and move within a second of a change with no whole-Lab read: an answer no longer reads the Lab again. A failed Inbox says the server's reason, and Retry, R and *as of · refresh* read it again. An ask from a worker run with no conversation is listed, from no named worker, with no reply box. This begins Shift Manager's move onto per-screen views (with its siblings, a task and its run, the roster and the snapshot's removal) (FIX-2774).

Until those follow-ups land, the roster's workers and a task's own page still read the Lab snapshot's asks and boards, so for a moment they can disagree with the Inbox: an ask can show in the Inbox before it shows beside its worker on the roster, and an ask from a run with no conversation shows only in the Inbox (FIX-2775, FIX-2776).
