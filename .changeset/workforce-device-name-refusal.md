A name anywhere in a workforce tree — team, worker, channel, document, kind or block — may no longer be one Windows reserves for a device (`con`, `prn`, `aux`, `nul`, `com0`–`com9`, `lpt0`–`lpt9`), since a tree holding one cannot be checked out on Windows whatever the extension (FIX-1357).
