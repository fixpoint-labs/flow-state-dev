# Security Policy

## Supported Versions

This project is currently in active development (Phase 1). Security fixes will be applied to the latest version.

| Version | Supported |
|---------|-----------|
| latest  | Yes       |

## Reporting a Vulnerability

**Do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability, please report it by opening a [GitHub Security Advisory](https://github.com/fixpoint-labs/flow-state-dev/security/advisories/new) on this repository.

Include as much detail as possible:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes

You can expect an acknowledgment within 48 hours and a more detailed response within 7 days.

## Disclosure Policy

We follow coordinated disclosure. We ask that you:

- Give us reasonable time to investigate and fix the issue before public disclosure
- Avoid exploiting the vulnerability or accessing user data
- Act in good faith
