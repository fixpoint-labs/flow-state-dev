# Ecosystem overview

The flow-state.dev ecosystem is a set of optional packages that build on the core block primitives. Pick what you need.

A full map of the ecosystem — pattern packs for multi-agent coordination, planning and reasoning, memory architectures, inference-time scaling, reactive loops, and human-in-the-loop gates — is being assembled. Until then, browse the package READMEs in the repo for what's currently published.
