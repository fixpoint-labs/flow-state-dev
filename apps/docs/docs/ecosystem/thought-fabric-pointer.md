# Thought Fabric

Thought Fabric is the cognitive layer built on top of flow-state.dev. It provides blocks, capabilities, and helpers for memory, attention, identity, and metacognition.

It has its own documentation section because it is larger than a single package page. Use flow-state.dev docs when you need runtime primitives: blocks, flows, state, streaming, server setup, and clients. Use Thought Fabric docs when you want agent behavior that models what to remember, what to focus on, and how a perspective should shape interpretation.

## How it fits

Thought Fabric exports normal flow-state.dev blocks. You compose them in sequencers, install their capabilities with `uses`, and register the resulting flow on the same server runtime.

If you are new to flow-state.dev, learn the runtime first:

- [Blocks](/docs/fundamentals/blocks)
- [Flows](/docs/fundamentals/flows)
- [Using capabilities](/docs/fundamentals/capabilities)
