# Upgrading to the 2026-11-24 release

This page lists what you change in your code when you move to the packages released on 2026-11-24. A name that leaves a package root has no alias: an old import fails to compile with "has no exported member", and the fix is the import the row names.

| Package | What changed | What to do |
| --- | --- | --- |
| Every published package | 1,107 exports leave the package roots. Some stay on another entry of the same package; the rest are gone | Import each name from the entry its package's changelog lists. A name with no other entry is not part of the public API |
| `core` | The root carries the names an app imports. The rest move to `@flow-state-dev/core/types`, and the coding-harness names to `@flow-state-dev/core/harness` | Import from those subpaths. `@flow-state-dev/core/internal` is for the framework's own packages |
| `core` | `ctx.emit.component` and the `component` item kind are removed. Structured content is a `data` item | Replace `ctx.emit.component(name, data, opts)` with `ctx.emit.data(name, data, opts)`, and register its renderer under `renderers.data` |
| `core` | A flow's `reads` and a scope's `client.derived` are removed. `defineFlow` refuses either key | Declare each one as a view: `views: { name: defineView({ scope: "session", block }) }`, with an `outputSchema` on the block |
| `core` | `LooseBlockContext` is removed | Type helpers with `BlockContext`. A block's `ctx` passes to them with no cast |
| `core` | `SessionView` (what `sessions.read` answers) is `PeerSessionView`; the model resolver's `RetryPolicy` is `ModelRetryPolicy`; `@flow-state-dev/core/blocks/sequencer` exports only `sequencer` | Rename the imports |
| `core` | The benchmark contract types (`BenchmarkTask`, `BenchmarkAdapter` and the rest) leave the root | Import them from `@flow-state-dev/testing/benchmark` |
| `core` | Exported names that said *row* or *collection item* for a resource, or *row* for a task, are renamed, and so are the matching refusal messages | Rename the imports as the changelog lists them, and update code that matches one of the messages |
| `core` | A three-part `gateway/provider/model` model string fails as an invalid format | Write `"gateway:provider/model"` |
| `core` | `defineFlow` throws when two declarations of one state field differ in type or default, and on a default factory that would never run | Make the declarations agree, and use a static default or declare the factory on the flow's session schema |
| `core` | A single resource with `runBy` and no state projection throws at definition | List the fields the client reads and writes: `client: { expose: ["pinned"] }` |
| `engine` | The exports are split across the root and `@flow-state-dev/engine/host`. Host, transport and store-adapter names live on `engine/host` | Move those imports to `@flow-state-dev/engine/host` |
| `engine` | `createFlowState` takes its flows as a list. A keyed record throws | Replace `flows: { chat: chatFlow }` with `flows: [chatFlow]` |
| `engine` | The `worker` option is `jobQueue`. `WorkerAdapter` is `JobQueueAdapter`, and the modes are `"enqueue-only"`, `"process-only"` and `"colocated"` | Rename the option, the types and any mode values in your environment |
| `engine`, `client`, `react` | Every send names its session. An HTTP send without one is refused with `400 session-required`, and `runAction` throws `SessionRequiredError` | Pass the conversation's id (`client.flow(f).createSession()`), or `oneOffSessionId()` from `@flow-state-dev/core/helpers` for a one-off run |
| `engine` | The app fires its own schedules. The router mounts the scheduled endpoint, and an app route on the same path is refused at startup | Remove your own cron routes and schedule mounts. On a serverless host, pass a `scheduler` such as `vercelScheduler()` |
| `engine` | JSON routes refuse a body not sent as `content-type: application/json` (415), and a cross-site browser mutation (403) | Send `content-type: application/json` on every `curl` or `fetch` POST to a flow route |
| `engine`, `node`, `next`, `vercel` | Every host refuses to serve an app that trusts `body.userId`, on any `NODE_ENV`. `serve()` throws on a network bind | Give each flow a principal resolver, or bind to `127.0.0.1`, or pass `allowUnauthenticated: true` for local work |
| `engine` | A custom `SuspensionStore` needs `listPendingForUser(query)` | Implement it, and run `createPendingUserSuspensionsConformanceTests` from `@flow-state-dev/engine/testing` against the store |
| `engine` | The `queue` and `scheduler` store profile slots are removed | Delete those lines from a typed profile |
| `engine` | `ctx.suspend({ reason: "human_approval" })` and `"human_input"` throw | Use `"user_approval"` and `"user_input"` |
| `engine` | `DispatchHandle` from a transport host is `InboundDispatchHandle`, and the bridge's `StreamEvent` is `StreamBridgeEvent`. `ChildSessionStatus` and `ChildSessionSummary` leave engine | Rename the imports, and import the child-session types from `@flow-state-dev/client` |
| `engine` | A request stream ends early for a reader more than 4 MiB behind, with no terminal event | Treat a stream that ends without a terminal `request.*` event as cut off, and resume it from the last event id |
| `store-sqlite`, `store-postgres` | The registry factories, per-store constructors and schema functions move to a `./host` entry | Import them from `@flow-state-dev/store-sqlite/host` or `@flow-state-dev/store-postgres/host`. `sqliteStores` and `postgresStores` stay on the root |
| `client` | `client.flow(kind).read(name, input, { sessionId })` is removed | Call `client.view(viewRef(flow, name), input, { sessionId })`, or `useView` in React |
| `client` | `ExecuteActionRequestBody`, `QueryValue` and `clientPackageMarker` are removed | Drop the imports |
| `react` | `session.resumeSuspension` is `session.answerSuspension`, and `resumedBy` is gone from its arguments | Rename the calls, and pass `session.answerSuspension` to `<SuspensionResolverProvider resolve>` |
| `react` | `buildItemRenderStream` is `conversationLines(items, turns?, options?)`. `ItemRenderSegment`, `BuildItemRenderStreamOptions` and `groupToolCalls` are removed | Call `conversationLines` and draw its `ItemLine` kinds |
| `react` | The voice primitives move to `@flow-state-dev/react/voice`, and the workforce panels (`Roster`, `BoardColumns`, `BoardList`, `WorkerDetail`) to `@flow-state-dev/react/workforce` | Import them from those subpaths |
| `react` | `useSuspensions({ reasons })` throws on `human_approval` or `human_input` | Filter on `user_approval` or `user_input` |
| `testing` | Benchmarking moves to `@flow-state-dev/testing/benchmark`, and `testBlock` replaces `testSequencer` and `testRouter` | Import benchmark names from the subpath, and test sequencers and routers with `testBlock` |
| `testing` | `testFlow` runs durably by default: a step that stops for a user ends the run `suspended` | Answer the stop with `run.answer(...)`, or pass `durable: false` to fail the run as before |
| `orchestration` | The task names leave the root | Import them from `@flow-state-dev/orchestration/tasks` |
| `orchestration` | The `"topological"` claim order and `topologicalClaimOrder` are removed | Use `"fifo"`, the default, or drop the option |
| `orchestration` | `withRetiredShapes` and `heldFromBlocked` are removed. A stored task with status `blocked` is declined `unknown-status` | Move stored tasks to the current statuses before you upgrade |
| `orchestration` | A model's `createTask` with no assignee is refused `assignee_required` unless the roster claims unassigned tasks | Set `claimsUnassigned: true` on a roster whose default worker takes them |
| `patterns` | The benchmark adapters move to `@flow-state-dev/patterns/benchmark`, which needs `@flow-state-dev/testing` installed | Change the import and install `@flow-state-dev/testing` |
| `patterns` | `/routedSpecialists` is `/routed-specialists` and `/eventActors` is `/event-actors`. Names the root re-exported live on their pattern's subpath, and the debate helpers drop their `Debate` infix there | Import from the kebab-case subpaths and the pattern's own subpath |
| `workforce` | The `*_ENTRY` constants leave the root | Name each entry by its string: `work`, `onTaskSteered`, `onMessageReceived`, `onWorkstreamOpened`, `onTaskSettled`, `routeSubscriptionEvent`, `deliverSubscriptionEvent` |
| `workforce`, `workspace` | Eleven names leave the roots, `taskBriefOf`, `taskBriefMetadata` and `TaskBrief` among them | Import the task-brief names from `@flow-state-dev/workforce/browser` |
| `workforce` | `reportProblem` answers the report's `status` in words, not `{ decision, reportId }` | Read `status`, `waitsIn` and `note` |
| `workforce` | `WorkforceClientSource` takes the client's `view` and `subscribe`, not `live` | Pass those from your client |
| `workforce` | `createWorkforceCapability` takes `roster` and `inventory`. `agents` and `catalog` are unknown options | Rename the options |
| `workforce` | The projects collections are written through a flow named `"projects"` (`PROJECTS_FLOW`), and `checkRepository` is a view | Register the project blocks' actions on a flow of that name, and install `views: { ...projects.views }` |
| `workforce` | Workers on the built-in flows are told the date, load a skill that fits, and summarize older turns, by default | Nothing, unless you want the old prompt. The changelog names each setting |
| `harness-manager` | `harnessRunChangesRead`, `harnessReadinessAction` and `harnessUsageAction` are removed | Use `harnessRunChangesView`, `harnessReadinessView` and `harnessUsageFlow` with its `usage` view |
| `harness-manager` | A coding run's branch starts with the app's prefix, not `conductor/` | Set `branchPrefix` on `harnessManager` or `harnesses` |
| `claude-code` | The package has one entry, the root. `./sdk` and `./cli` are gone, and names say `ClaudeCode` (`SDK_SESSION_ID_KEY` is `CLAUDE_CODE_SESSION_ID_KEY`, `listClaudeModels` is `listClaudeCodeModels`) | Import from `@flow-state-dev/claude-code` and rename as the changelog lists |
| `claude-code` | The `@anthropic-ai/claude-agent-sdk` peer range is `>=0.3.316 <0.4.0`, and a version outside it is refused | Install an SDK in that range |
| `codex`, `cursor` | `estimateCodexCost` and `estimateCursorCost` are removed | Read `handle.cost` from the block's handle |
| `devtool` | `getAssetPath()` is `getDevToolAssetPath()` | Rename the call |
| `bullmq` | `bullmqWorker` is `bullmqJobQueue`. The schedule entry `@flow-state-dev/bullmq/schedules` is removed | Rename the call, and drop the schedule wiring: the job-queue processes fire schedules |
| `vercel` | `@flow-state-dev/vercel/schedules` is removed, and `vercelPostgresStores()` lists no `scheduler` capability | Replace the per-schedule cron routes with `vercelScheduler()` and its one route |
| `workspace` | Child processes the workspace starts get an allowlisted environment, not the host's whole one | Pass any variable a setup or check needs through `setup.env` or the check's `env` |
