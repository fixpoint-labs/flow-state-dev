# Settings

Settings is where you give the Lab your keys for the tools its coding runs can use. It lists each MCP server the Lab offers, such as Linear, and whether you've set a key for it, with the date you did. MCP, the Model Context Protocol, is how a coding agent reaches a tool outside its checkout.

Paste a key to set it, paste another to replace it, or clear it. The page never shows a key back, not even its last characters, so keep your own copy if you need one. Your keys are yours: a run you ask for uses them, and nobody else's run does.

A project turns a server on for its runs. Your key is what each of your runs uses on it. Both are needed: a key with no project naming the server does nothing, and a project naming it with no key from you gives your runs no access, said in each run's session.

The run itself never gets your key. The Lab connects to the server with it and hands the run only the server's tools. See [Tools a project's coding work gets](../workforce/projects.md#tools-a-projects-coding-work-gets) for how that works, and what it does and doesn't protect.

A Lab that offers no MCP servers says so here, and there is nothing to set.
