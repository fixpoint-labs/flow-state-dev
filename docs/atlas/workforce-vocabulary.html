Workforce vocabulary inventory

Review notes. How each word is used in this repo today, including where two uses sit on one word. It does not settle names, and it is not the published Workforce glossary.

Read it to see bloat before changing anything. seat and role are an open review, not a settled kill.

Word Used today as Where uses collide
worker A WORKER.md on a team, hired into an addressable flow copy. Hiring that file is how the worker becomes addressable. A later session is more work for the same worker, not another hire. Orchestration also calls a board block, tool, or skill agent a worker. A task assignee names that board worker, never a hired workforce worker.
session A piece of work opened against an already-hired worker, the same way you open one against any flow. A channel is also “a session on the channel kind.” Same Layer 1 word, two product places.
hire hireWorkforce turns a worker record into a flow copy. A runtime hire writes a roster row so the worker survives a restart. Easy to treat a new session as a second hire. Today it is not.
fire Removes a runtime-hired worker. File-declared workers leave when their folder is deleted. A fire can wait for a person’s approval.
seat Published docs: “a hired worker is a seat.” Atlas: a roster slot / flow instance from WORKER.md. Code still uses the word in seatPost, seatAuthored, wakeMemberSeats, the seat pane, SeatDetail, seat-hire, and seatId. Product noun and code identifier share one word. Whether seat stays a product noun is an open review.
role Not a WORKER.md field. Chat messages use role (user / assistant / system). Some prompt templates say state.role. The atlas calls worker roles kinds / opinions. Chat shape, prompt state, and “what job this worker does” share one word. Whether role is a product noun is an open review.
agent The built-in flow kind named agent (what a WORKER.md with no flow: runs on). Atlas also uses agent as a later opinionated worker, not a Layer 1 type. Also an orchestration skill agent: a persona plus tools that claims board tasks. Three live uses.
member On a channel: a name on that channel’s member list. Listing someone does not make them hear a post. The listener is a hired worker whose kind declares onChannelPost. On a project: a person (userId) who may read and post in the project’s room. Two lists, two kinds of thing.
persona A WORKER.md that declares persona: is refused. Orchestration still uses persona for a skill agent’s prompt. Refused as a workforce setting, live as an orchestration noun.
channel Docs, folders, and code: a named session on the channel kind, declared as teams/<team>/channels/<name>/CHANNEL.md, with members, a charter, and a transcript. Product talk and an in-flight rename also call this a mailbox. Same pipe, two names.
mailbox The name used in the in-flight channel rename, and in some product copy, for that same pipe. Shift Manager and FIX-1748 treat a workstream’s conversation as a mailbox. Collides with channel. Also collides with the agent-mailbox board (open PRs as handles for agents outside this repo), which is a different pipe.
inbox Shift Manager’s list of asks (approvals and questions) across many channels / mailboxes. Never one channel. Knowledge Hub has a different capture inbox. Easy to treat inbox as a synonym for one mailbox.
room The shared conversation for one project. Project members read and post there. Anyone in the org can see the project exists; only members read the room. Sits next to channel / mailbox. One is a worker pipe, one is a project’s shared place.
workstream A mailbox (today: a channel) plus the boards it holds, under a project. Shift Manager’s sidebar and headings use this word. The conversation part is the mailbox; the boards sit beside it, not inside it. Collides with mailbox and room. Two words for “the talk” and “the talk plus its boards.”
project An organization row: title, brief, owner, members, the workstreams it groups. Not a file. Each project has one room.
org The tenant every request runs in. Organization-level workers live under workforce/org/workers/ and hire by folder name alone (chief-of-staff). org the folder vs organization the tenant. Two spellings, one tenant.
team A folder of workers, optional TEAM.md, under workforce/teams/<name>/. Shift Manager’s TEAMS list is this grouping. Workforce opinion, not a Layer 1 type.
staff Shift Manager sidebar row for organization-level workers (anyone under org/workers/, including the chief of staff). Reads as a third grouping beside team and org. It is a chrome row, not a type.
lab A served workforce from one fsdev.config. Shift Manager opens a Lab. Today’s chrome still says seats and channels. Not an org, not a team, not a project.
desk Informal name for a support team, plus leftover ids (support.desk, desk-clerk). Not a type. Easy to teach as one.
roster The set of worker records you hire, and the stored collection of runtime hires (workforce/roster/*). “Who did we declare?” and “who is hired right now?” are different questions on one word.
inventory Org-scoped rows that a seat or channel was registered. A row is not “open” or “working now.” Easy to mix with roster.
ask A question or approval waiting on a person. Inbox lists asks across channels / mailboxes. Not a mailbox, not a session.
Shift Coordinator Shift Manager’s opening chrome (/ / /cos): asks, runs, and the conversation with the Lab’s chief-of-staff worker. The empty state says “This Lab declares no shift coordinator.” Chrome name and worker id are different words for one worker.
chief of staff The worker id and folder: org/workers/chief-of-staff/. Chrome says Shift Coordinator. Same worker, two names.
board worker / assignee Orchestration: the block, tool, or skill agent that claims a task. A task’s assignee never names a hired workforce worker. The worker collision above.
seatPost Channel action that posts a line as that worker’s own. Sets seatAuthored. A client or dispatched post is a different action and does not. The name says seat. See seat.
seatAuthored Flag on a transcript line: it arrived through that worker’s own seatPost or its answer. Other members are not woken. A claimed author field does not set it. The name says seat. See seat.
wakeMemberSeats Notify block for a channel post. On an unrouted post it wakes each member whose hired worker declares onChannelPost, once. On a routed post it wakes only the chosen member. Skips the wake when seatAuthored is set. The name says seat. See seat.
onChannelPost Internal entry a kind declares to hear a channel post. Built-in agent declares it. A member list name without this entry hears nothing. The name says channel. See channel / mailbox.
seat pane / SeatDetail UI for one hired worker’s kind and instructions. Kitchen-sink draws it in the rail. The component is SeatDetail. The name says seat. See seat.

Atlas listing: index.html. Published how-tos stay under apps/docs/docs/workforce/ and are unchanged. Identifiers are not renamed here.
