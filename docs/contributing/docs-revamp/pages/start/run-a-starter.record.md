## 2 · Cold-read questions

Written by an agent that had seen no draft. Pass 9 got these unchanged.

1. You have cloned nothing yet and want the Teammates starter running. Before you type a command, what two things do you need?
   Answer: A clone of the repository, which needs Node.js 22 or newer and pnpm, and one model key. For the starter as it ships, OPENAI_API_KEY or AI_GATEWAY_API_KEY works as is (rd:32, rd:51; flag 10). A coding-agent sign-in and a search key are not needed to talk to a worker (rd:55, rd:57).
2. You put OPENAI_API_KEY in a file and ran `pnpm --filter @flow-state-dev/teammates dev`. What is the file called and where does it go, and does the key end up in a commit?
   Answer: A `.env.local` at the repository root, with a line like `OPENAI_API_KEY=sk-...`. A file named `.env` is not read (flag 2, env:81-104, rd:47). `.env.local` is git-ignored, so the key stays out of commits (.gitignore:7). A key already set in your shell wins over the file (env:62-74).
3. The app opens at the `App:` address, you pick Chief of Staff and send "What can the team do for me?", but no answer comes. Where does the page tell you to look first, and what do you do? *(edge case)*
   Answer: Look at the conversation first. A failed turn leaves one line under the worker's name with the reason, and the newest turn has a Retry. A missing key is the likeliest reason. Fix the key, restart (keys are read at start), and press Retry. If the conversation shows nothing useful, check the terminal running the dev command next, then the DevTool (failed-turn.test.tsx, request-recovery.tsx:45-52, cm:1224-1231, env:62-74; section 5 item 7).
4. You only have an ANTHROPIC_API_KEY. You add it to `.env.local` and start the app. Will Teammates work as shipped? *(edge case)*
   Answer: Not as is. The default model is openai/gpt-6-luna, and the starter's helper calls always use an OpenAI model whatever TEAMMATES_MODEL says. Another provider's key also needs that provider's package installed and the model setting changed. The page says to use OPENAI_API_KEY or AI_GATEWAY_API_KEY and sends other providers to the model setup pages (flag 4, th:80-81, th:410-411, rd:51, tc:52).
5. You want to change what researcher is told to do. Which file do you open, and when does your change take effect? *(edge case)*
   Answer: labs/teammates/workforce/teams/teammates/workers/researcher/WORKER.md. One folder per worker sits under workforce/teams/teammates/workers/ (chief-of-staff, researcher, writer, plus the coding agents). The body is its instructions; `description` is the only required key and `name` is the display name. The starter does not watch files, so the edited instructions apply on the next start (rd:65, rd:82, tp:12, packages/workforce/README.md:115).
6. You talk to writer, stop the server with Ctrl+C, and start it again the next day. Is the conversation still there, where is it kept, and how would you start from nothing? *(edge case)*
   Answer: Yes. Conversations, a turn a crash cut off (listed as interrupted) and the task it started survive a restart. They are kept in a SQLite file, by default labs/teammates/.fsdev/teammates.sqlite, which git ignores. Each worker has one conversation per user, and the starter runs as one user, so it is yours. Stopping the server clears nothing. To start fresh, delete .fsdev/ in labs/teammates while the server is stopped (this one is marked verify on the sheet) (th:48-49, th:418-420, tr:211, rd:59, first-run.ts:23, Resetting).
