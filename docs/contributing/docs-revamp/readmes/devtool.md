# @flow-state-dev/devtool

The pre-built DevTool that `fsdev dev` serves beside your flows. Install it and `fsdev dev` picks it up.

```bash
pnpm add -D @flow-state-dev/devtool
```

```bash
fsdev dev
```

Reference: [the `devtool` section of the Flow State API reference](https://flow-state.dev/docs/reference/api/devtool).
