# @flow-state-dev/fsdev

The `fsdev` command: run a flow, run one block, and open the DevTool, from the terminal.

```bash
pnpm add -g @flow-state-dev/fsdev
```

```bash
fsdev run my-agent chat -i '{"message": "Hello!"}'
```

Reference: [the `fsdev` section of the Flow State API reference](https://flow-state.dev/docs/reference/api/fsdev).
