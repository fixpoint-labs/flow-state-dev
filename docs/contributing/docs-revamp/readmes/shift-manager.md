# @flow-state-dev/shift-manager

The browser app a Workforce Lab is worked through. Point it at a Lab's config.

```bash
npm install @flow-state-dev/shift-manager
```

```bash
npx shift-manager --config ./fsdev.config.mts
```

Reference: [the `shift-manager` section of the Flow State API reference](https://flow-state.dev/docs/reference/api/shift-manager).
