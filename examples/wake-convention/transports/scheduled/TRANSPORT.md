Not a product noun. This is today's scheduled adapter, registered the same
way GitHub is.

Cron is **seat-local**: `workers/night-watch/` says "every 4 hours." This
folder does not list who wakes. It only registers that ticks exist.

The host still owns the clock process (ops). The seat owns the interval.
