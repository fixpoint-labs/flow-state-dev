# model-strings › it routes the registry grammar

**Issue:** FIX-1495
**Outcome:** An app author writes a model string the way AI SDK's provider registry writes it, for a generator or an evaluator, and the call reaches the route the string names: `vercel:openai/gpt-5.4-mini` through the gateway, `openai:gpt-5.4-mini` to OpenAI only, `triage:native` to the provider the app registered as `triage`. A bare `openai/gpt-5.4-mini` still resolves however it can. A string in the removed `gateway/provider/model` form fails before any request, with an error naming its colon spelling. The repo guard refuses a new one.
**Input:** `fixtures/input.json`, a one-word factual question for the generator and a support ticket plus a yes/no question for the evaluator. Held-out: any question and any ticket must pass; nothing asserts on what the model says, only that it said something and which route served it. Any other gateway model must pass too, and so must a model id that carries its own `:` (`openrouter:openai/gpt-oss-20b:free`, run when OpenRouter's key and package are both present).
**Signal:** Leg (g), one `runAction` per string on the default resolver: `g:colon-text` / `g:slash-text` the generator returns text; `g:route` the block_trace row's model identity names the expected gateway (`vercel` for `vercel:openai/…`; for the bare slash string, none with `OPENAI_API_KEY` and `vercel` without; none for `openai:…`); `g:id` the identity's model id contains `gpt-5.4-mini`; `g:pinned` without `OPENAI_API_KEY`, `openai:gpt-5.4-mini` fails naming that key instead of falling through; `g:legacy` the slash multi-hop string fails with an error containing `"vercel:openai/gpt-5.4-mini"` and zero requests leave the process. Leg (e): `e:colon-decision` `vercel:typesafe-ai/jev` and `triage:native` (a provider the check registers under `providers`, serving a real evaluation model) each return a boolean decision; `e:route` the first's identity names `vercel`, the second's names no gateway. Leg (r): `r:clean` the guard exits 0 on the repo; `r:planted` it exits non-zero with one planted slash multi-hop string.
**Anti-game:** A hollow pass asserts on the parser's output or on a stubbed provider; both pass while the request never reaches the gateway with the right id. The check reads only the run's output and the trace row's identity, which the model wrapper stamps from the route that served the call. `triage:native` serves Jev re-wrapped without the gateway's identity record, so its "no gateway" can only come from the resolver taking the provider lookup.
**Model:** real — `openai/gpt-5.4-mini` and `typesafe-ai/jev` through Vercel's AI Gateway (`AI_GATEWAY_API_KEY`); direct OpenAI with `OPENAI_API_KEY` when set.
**Run:** `pnpm tsx goals/model-strings/registry-grammar/run.mts`
**Controls:** `GOAL_CONTROL=colon-off` makes the resolver refuse every colon string, the colon lane switched off. Must FAIL on `g:colon-text` and `e:colon-decision`, and on nothing that only tests the slash lane.
