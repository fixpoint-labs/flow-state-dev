# workforce-conventions › it produces the roster from files alone

**Issue:** FIX-1335
**Outcome:** Someone describes their AI workers in folders — one Markdown file each, grouped by team — points the app at the root, and the app has its workers: every one with its own identity, its own settings and its own instructions, with no worker written in TypeScript and nothing registered anywhere in the path. A folder that was supposed to be a worker and isn't gets named, so the app can refuse to boot a worker short.
**Input:** `fixtures/workforce/` — two teams, a worker called `lead` in each, a thin seat with no instructions, a folder whose worker file is mistyped (`WORKERS.md`), and a team-level `resources/` folder. `fixtures/input.json` holds the expected identities, settings and per-worker markers. Held out: nothing in the loader knows any of these values; swap the tree and `input.json` together for another valid pair and a correct implementation still passes.
**Signal:** The returned roster is exactly the three identities the tree describes; each record's `declared` equals what its file wrote; each worker's body contains the marker written only in its own folder and none of another worker's; `errors` names exactly the mistyped folder; `resources/` is not reported. PASS prints the roster and the reported slot; any mismatch is a FAIL.
**Anti-game:** A hollow pass here would count workers, or assert that `workers.length === 3`, or check that each record merely *has* a body — all of which survive a loader that hands every worker the same instructions, or a default set. So the check must not assert on shape, on counts alone, or on any value the loader itself produced. It grades against the fixture: the marker tokens (`TIDEPOOL-4417`, `SANDPIPER-9023`) appear in exactly one folder each on disk, so a body can only carry the right one if that folder's file was actually read. The two same-named `lead` workers are the cross-contamination probe — anything keyed by bare name puts one body on both and fails. The thin seat is the inverse probe: it must come back with no instructions, so a loader that invents default instructions fails rather than passing.
**Model:** none — the loader reads files and returns data; no model is contacted.
**Run:** `pnpm tsx goals/workforce-conventions/files-alone-produce-the-roster/run.mts`
