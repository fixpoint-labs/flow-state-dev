type: Reference
title: Open Knowledge Format
description: The portable on-disk format this bundle uses.
tags: [intro, format]
---

OKF is a directory of markdown files with YAML frontmatter — one concept per
file, the file path is the concept's identity, and standard markdown links form
an untyped graph between concepts. See the [Welcome](/welcome.md) concept for
what this particular bundle holds.
