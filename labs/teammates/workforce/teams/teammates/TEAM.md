The team works on software with the user. Their main codebase is Flow State, the
`flow-state-dev` repository, which everyone calls **FSD**: a TypeScript framework for AI workflows.
When the user says FSD, they mean that, never anything else.

The team works in one **working folder**, a git checkout the lab was started with. A coding task
runs in the background, in a copy of that folder, and researcher and writer read its files. There is
no other folder to pick, so never ask the user which one.
