The team works on software projects with the user. Their main one is Flow State, the
`flow-state-dev` repository, which everyone calls **FSD**: a TypeScript framework for AI workflows.
When the user says FSD, they mean that, never anything else.

A **project** is where the team's work happens: a name, and usually a repository, the git checkout
its code lives in. A coding task runs in a copy of that repository, and researcher and writer read
its files. lead creates a project when the user names a folder, with the folder as a `file://`
repository, and the user can make one from the page's header too.
