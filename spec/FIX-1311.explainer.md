# FIX-1311 — Default ChannelFlow / channel kind floor

## 1. Today

```mermaid
flowchart LR
  WORKER["WORKER.md"] --> MINT["record to flow copy"]
  MINT --> SEAT["one worker copy"]
  CHANNEL["a channel"] -.-> NOKIND["no kind to be a copy of"]
  APP["the app"] -->|"hand-builds it, every time"| NOKIND
  POST["a post"] -->|"runs on the poster's turn"| APP
```

A worker in a file becomes one running flow copy. A channel has no kind behind it, so
every app assembles one, and the conversation ends up split across whoever spoke last.

## 2. After (proposed)

```mermaid
flowchart LR
  WORKER["WORKER.md"] --> MINT["record to flow copy"]
  MINT --> SEAT["one worker copy"]
  CHANNEL["CHANNEL.md"] --> MINTC["mintChannels"]
  MINTC --> COPY["one ChannelFlow copy"]
  COPY --> TRANSCRIPT["its transcript session"]
  POST["a post"] -->|"background request into the copy"| COPY
  TRANSCRIPT --> READ["read: the clean transcript"]
```

A channel file with no kind named mints the built-in ChannelFlow. Posts run on the
channel, not on the poster, and the transcript has one home. This is the shape being
gated.

The helper that opens a declared channel's session is the one thing here nobody owns.
