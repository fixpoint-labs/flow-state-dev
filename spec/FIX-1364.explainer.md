# FIX-1364 — Memory attach + gap honesty for the agent kind

Visual companion to [`spec/FIX-1364.md`](./FIX-1364.md). Decides nothing.

## 1. Today

```mermaid
flowchart LR
  App[App] -->|catalog, skills, model| Factory[defineAgentWorkerFlow]
  Factory --> Kind[agent kind]
  Kind --> Seat[worker seat]
  Seat --> Model[model call]
  Mem[memory package] -.->|no way in| Factory
  Fork[fork the factory] -.->|only option| Kind

  classDef blocked stroke-dasharray: 5 5
  class Mem,Fork blocked
```

An app can hand the factory a tool catalog, skills and a model. There is no door for
memory, so an app that wants a worker who remembers must copy the factory and edit it.

## 2. After (proposed)

```mermaid
flowchart LR
  App[App] -->|"catalog, skills, model<br/>+ uses, resources, isolate"| Factory[defineAgentWorkerFlow]
  Factory --> Kind[agent kind]
  Kind --> Seat[worker seat]
  Seat --> Model[model call]
  Mem[memory package] -->|"capability + resources"| App
  Store[(per-worker storage)] --- Seat

  classDef added stroke-width:3px
  class Store added
```

Three generic doors: capabilities to attach, storage to declare, and whether each worker's
storage is its own. Memory passes through them like anything else. Called with no
arguments, the factory still produces a worker with no memory.

*This is the shape being gated, not built yet.*

## 3. Where the decision fell

```mermaid
flowchart TD
  Issue[FIX-1364] --> Attach[attach: the seam]
  Issue --> Honesty[honesty: what we teach]

  Attach --> Generic[generic uses/resources/isolate]
  Attach -.->|rejected| Shaped["a memory: option or withMemory helper"]
  Generic --> Fence[worker's tools list stays the only tool door]

  Honesty --> Proved["per-worker memory WORKS<br/>one flag, no new primitive"]
  Honesty --> Residual[residual limit: isolation is per kind, not per tier]
  Residual --> Ticket[filed, not built]

  classDef rejected stroke-dasharray: 5 5
  classDef finding stroke-width:3px
  class Shaped rejected
  class Proved finding
```

A memory-shaped option was rejected: it would make workforce depend on the memory package.
A POC on this branch overturned the contract's assumption that per-worker memory was an
unproved gap. What remains is narrower and gets filed.

## What this leaves alone

The memory package's API, the default worker (still no memory), and per-worker memory
settings in worker files — there are none, by design.
