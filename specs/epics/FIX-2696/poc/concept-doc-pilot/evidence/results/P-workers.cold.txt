**R2. What is a kit?**

**R3. What is a flow?**
A flow is the piece of backend that handles each message for a worker. A worker with no `flow:` setting runs on the built-in agent (a model, its instructions, tools, and the conversation so far). A custom flow, such as `src/flows/request-triage/flow.ts`, can add fixed steps, branching, or a review before anything is sent.

**R5. Which one do you change for each?**
(a) A worker's instructions: edit the body of its `WORKER.md` file, below the second `---`.
(b) Adding a whole feature such as coding agents: the page does not say directly. The closest match is a kit, since workers come from the Workforce kit, but the page never says kits are how you add features like coding agents.
(c) One step inside how a request is handled: that would be the worker's flow (`src/flows/<name>/flow.ts`), which can have fixed steps and branching. The page does not name a smaller unit than the flow.
